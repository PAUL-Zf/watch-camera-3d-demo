# WATCH / VISION

本地离线的手表摄像头 3D 视野概念模拟器。比较屏幕面前摄、表体背面后摄、12 点钟侧摄、3 点钟侧摄在佩戴姿势及表体翻转过程中的视野。

版本：0.1.1；项目采用 MIT 开源许可证，见 `LICENSE`。

## 0.1.1 后摄画面方向修复

0.1.0 只指定镜头光轴，未明确传感器画面上方向，导致表体立起后后摄的画面倒置。0.1.1 使用光轴和安装上方向建立完整相机坐标系；前后摄的画面上方向均朝表体 12 点钟侧。这相当于对旧版后摄安装方向作 180° 滚转校正，而非单轴翻转或自拍镜像。

新增每路“画面旋转 · 传感器安装”滑块及 0° / 90° / 180° 快捷键，模拟传感器绕光轴的安装旋转，保持镜头位置和拍摄方向不变。预览、视锥、目标提示和导出 PNG 使用同一相机方向。不会自动把任意佩戴姿势的画面拉平到世界水平线，仍保留真实随动关系。旧 JSON 配置自动补零旋转值。

## 直接运行

下载 `dist/watch-camera-demo.html`，使用近期版本的 Chrome / Edge 双击打开。打开后无需互联网、npm、Python、本地服务器或外部模型文件。网页使用 WebGL 2；图形功能需要浏览器允许硬件加速。

**请下载 HTML 文件后打开，GitHub 文件预览页不是 Demo。**

建议电脑浏览器窗口宽度在 1280 像素以上。窄窗口下四路画面会移到主视图区下方。

## 建议的演示顺序

1. 初始“抬腕看表”：观察 A 前摄中的人脸；B 后摄此时通常被底座遮挡。
2. 点击“抬腕立起 · 双摄”：表体绕 6 点钟侧铰链立起 90°。观察 A 前摄看脸、B 后摄看前方标识及物体。
3. 在 0°、45°、90° 之间切换，观察后摄视野逐步露出。表体没有离开腕上的底座。
4. 点击“腕部”放大：查看钟点标记、活动表体、固定底座及彩色镜头位置。
5. 点击 A / B / C / D 画面，分别修改安装位置、安装部件、水平偏转、上下倾斜、水平视场角。
6. 将某一路改为“腕上固定底座”，对比其不会随表体立起而转动的效果。底座背面镜头仍会受到手腕遮挡。
7. 切换“自然下垂”并播放摆臂。暂停会冻结当前姿势，便于观察。
8. 导出 JSON 配置，或保存四路对比 PNG，记录讨论结果。

## 已实现

- 简化成人模型、手臂与手掌，左腕 / 右腕佩戴。
- 肩部抬臂、肘部弯曲、前臂旋转和腕部弯曲。
- 独立的表带、固定底座、连接件、铰链与可活动表体。
- 表体立起 0–120°、连接件旋转 -180–180°，用于概念观察。
- 四个可独立配置 / 开关的摄像头槽位，默认同一手表上的四个候选位置。
- 屏幕面、表体背面、12 / 3 / 6 / 9 点钟侧面，共六个安装位置。
- 镜头水平偏转、上下倾斜、画面旋转 -180–180°、水平视场角 40–130°；画面比例 4:3。
- 一个共享 WebGL 渲染器，最多五个视角：外部观察 + 四路传感器视图。
- 所选 / 全部视锥、人体显示与遮挡开关、鼠标与键盘场景操作。
- 人脸采样点及场景目标的视野 / 遮挡提示。
- JSON 导入导出、浏览器本地保存、四路对比图 PNG 导出。
- 全部代码与程序生成的模型 / 纹理内嵌于单一离线 HTML。

## 模型约定

- 世界坐标：Y 向上，Z 是人体前方。
- 表体坐标：Y 是屏幕面的外法线，Z 朝 12 点钟方向，X 朝 3 点钟方向。
- 铰链位于 6 点钟侧，12 点钟侧向上抬起。连接件旋转可改变立起方向；这是通用概念结构，不是品牌实机结构复刻。
- 表背摄像头位于活动表体与屏幕相反的一面。平放时通常被底座挡住；立起后随表体运动，配合抬腕可拍前方。
- “立起”与“完全拆下手持”是不同状态。本版实现腕上立起，不包含完全拆下后的持握模型。
- 前后摄默认光轴相反；它们的实际世界朝向由身体姿势、前臂旋转、腕部弯曲、表体翻转共同决定。
- 显示的 FOV 是水平视场角，代码换算为 Three.js 的垂直 FOV。钟点标记以表体为参照，不以观察者视角为参照。
- “人体显示 / 遮挡”关闭时人体也不再参与遮挡，用于诊断镜头方向，不能作为真实佩戴效果。
- 视锥和彩色镜头标记仅在外部观察视图可见；它们不会出现在传感器画面中，也不参与遮挡。

## 开发与验证

开发环境使用 Node.js 20 或以上：

```bash
npm ci
npm run check
```

`npm run check` 执行测试、构建和离线资源检查。独立执行 `npm run build` 会更新 `dist/watch-camera-demo.html`。

代码结构：

```text
src/kinematics.js      关节层级、摄像头安装与 FOV 换算
src/scene.js           人体、手表及场景参照物
src/config.js          配置数据与导入校验
src/app.js             界面、交互、同步渲染及导出
src/index.html        页面结构
src/style.css         响应式界面
scripts/build.mjs     构建单文件离线 HTML
scripts/check-offline.mjs  离线资源与脚本语法检查
tests/                几何、遮挡、配置及 UI 事件测试
```

本版自动验证覆盖：复合关节运动、光轴与铰链关系、表体 / 底座随动区别、后摄平放遮挡与立起解除遮挡、镜头在表壳外、预设的人脸 / 环境入镜、配置导入校验、四路槽位操作、暂停冻结、导出流程和无 localStorage 时的回退。

**验证限制：UI 测试使用 JSDOM 和渲染器替身；几何与遮挡测试使用真实 Three.js 数学、投影和射线检测。没有完成真实浏览器 GPU 像素渲染、视觉布局检视、PNG 实际色彩与公司电脑离线启动验证。** 请参考 `VALIDATION.md` 完成现场检查。

## 适用范围

适合讨论“哪个位置能看到什么、怎样抬腕或立起、会被什么挡住”。不模拟成像清晰度、曝光、低光、镜头畸变、防抖、人脸识别算法或真实人体机械活动约束。人脸提示只是少量点的可见性判断，不是覆盖率测量。手表尺寸、人体比例、铰链范围及镜头参数都是示意值，不能据此作实机定型结论。
