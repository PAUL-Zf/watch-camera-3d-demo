# WATCH / VISION

本地离线的手表摄像头 3D 视野概念模拟器。比较屏幕面前摄、表体背面后摄、12 点钟侧摄、3 点钟侧摄在佩戴姿势及表体翻转过程中的视野。

版本：0.3.1；项目采用 MIT 开源许可证，见 `LICENSE`。

## GitHub Pages 在线发布

发布文件已准备在 `docs/index.html`，与单文件离线版本完全相同。`docs/.nojekyll` 禁用不需要的 Jekyll 处理。启用 Pages 后可在线使用全部浏览器功能，离线 HTML 仍可独立下载运行。

首次启用（需要在 GitHub 仓库设置中操作一次）：

1. 使用仓库所有者或管理员账号打开 [Pages 设置](https://github.com/PAUL-Zf/watch-camera-3d-demo/settings/pages)。
2. 在 **Build and deployment** 中，将 **Source** 设为 **Deploy from a branch**。
3. 将 **Branch** 设为 **main**，旁边目录设为 **/docs**，点击 **Save**。
4. 打开 [Actions](https://github.com/PAUL-Zf/watch-camera-3d-demo/actions)，等待 **pages build and deployment** 成功；也可返回 Pages 设置查看 **Visit site**。
5. 部署成功后访问 [在线 Demo](https://paul-zf.github.io/watch-camera-3d-demo/)。此链接是预期地址，准备文件本身不等于已启用 Pages。

后续更新：执行 `npm run check`（或 `npm run build`），构建会同时更新 `dist/watch-camera-demo.html` 和 `docs/index.html`；将新生成的 `docs` 文件提交到 `main` 后，Pages 会自动发布。不必每次重新设置，也不用手动复制网页。

若尚未看到网站，先检查 Actions 的部署是否成功。初次发布可能需等待最多约 10 分钟；不要把源目录选成仓库根目录，否则可能显示 README 而非 Demo。若没有 Settings 或 Save 无法操作，确认当前登录账号对该仓库具有管理员或维护者权限。

官方说明：[配置发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [创建 Pages 网站](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

## 0.3.1 修复快捷观察视角的真实点击

全身 / 腕部 / 脸部 / 餐桌按钮的定位逻辑此前已存在，但按钮位于OrbitControls拖拽区域内。鼠标 / 触摸按下事件冒泡到主视图区时，OrbitControls会捕获指针，后续pointerup落在主视图区而不是原按钮，导致无法产生正常按钮点击。

本版隔离工具栏的pointerdown事件，保留场景空白区域拖拽；工具栏方向键不再同时旋转场景。点击按钮会定位外部观察镜头并显示选中高亮；先清除拖拽阻尼的残余运动，防止切换后镜头继续漂移。工具栏位于加载提示上方，3D尚未就绪时明确显示无法定位提示。切换视角不会更改人体姿势、模组配置、四路CAM的位置方向或HFOV。

新增真实OrbitControls事件路径的回归检查：修复前鼠标按下按钮会请求主视图区指针捕获，修复后鼠标和触摸按钮均不触发捕获，但场景拖动仍触发捕获。检查四种观察视角在后续帧中稳定、选中反馈正确、人体和四路CAM配置及变换保持不变。

## 0.3.0 模组尺寸与照片分辨率（历史版本）

每个 A/B/C/D 镜头独立设置模组宽度 **2–12 mm**、模组厚度 **1–8 mm**，默认 **6×6×3 mm**。3D 中增加简化方形封装和玻璃入口，跟随当前安装部件、位置和镜头朝向；宽度同时作为两个横向尺寸，厚度沿镜头后方延伸。关闭镜头时隐藏对应模组。模组是场景实体，可进入其他镜头的遮挡检测；原彩色标记仍只出现在观察视图，并随封装宽度缩放。

封装几何是空间包络示意，没有镜片组、传感器芯片或表壳开孔 / 碰撞求解。尺寸调整不会移动光学入口，不会推算像素数量、HFOV、焦距或光学清晰度；不同镜头封装可能相互重叠或超出安装面的可用空间，需要结构验证。模组厚度延伸到表壳内部，外部正视图可能无法直接观察厚度差异。

照片分辨率独立选择：

| 档位 | 实际输出尺寸 | 像素数量 |
| --- | --- | --- |
| 约30万 | 640×480 | 0.3072 MP |
| 约200万 | 1600×1200 | 1.92 MP |
| 约500万 | 2592×1944 | 5.038848 MP |
| 约800万 | 3264×2448 | 7.990272 MP |

全部保持4:3；HFOV仍按完整水平视场角定义。默认保留此前的640×480。四路实时小窗口为按界面大小渲染的缩放预览，不用于判断原尺寸细节；点击“拍摄主摄”按当前选定输出网格生成静态照片，提供适应窗口、100%原尺寸（可滚动查看局部）和不带文字边框的原尺寸PNG下载。100%表示一个图像像素对应一个CSS像素，操作系统 / 浏览器设备像素比不改变导出文件的像素数量。主摄关闭时不能拍摄。

“四路缩略对比PNG”先按各镜头独立分辨率采样，再统一缩放至640×480拼版（总图1280×1216），并标注原始照片尺寸与模组尺寸。要保存原始分辨率，请使用主摄照片查看器。单次操作顺序处理照片、释放临时渲染目标，关闭查看器后释放原尺寸画布；8MP照片仍会产生较高的瞬时显存 / 内存消耗。设备最大纹理尺寸不足时明确提示选择较低分辨率。

侧栏按实际可用空间自动切换控件行高和间距，保留全部参数和操作；原尺寸照片查看器内部允许滚动查看局部，主工作台仍保持一屏布局。

配置升级到schemaVersion 4，导入v1 / v2 / v3时自动补齐默认模组与分辨率，保留已有姿势和镜头参数；支持本机保存、导入、导出及单镜头 / 全部重置。

只模拟输出像素采样，未增加曝光、低光噪声、对焦、镜头MTF、畸变或食物识别模型；高分辨率示意场景不能等同于真实相机拍出的清晰度。尺寸与原生像素关系背景：[Basler成像质量资料](https://assets-ctf.baslerweb.com/dg51pdwahxgw/7HRh0r6ZgUTS13O3PMGU8d/bf82ab927607ab384703a1057889bc60/BAS1502_White_Paper_Image_Quality.pdf)、[Edmund Optics传感器与镜头](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/sensors-and-lenses/)。这些档位是模拟输出规格，不代表已经选定实机模组。

## 0.2.4 餐桌初始视图展示完整人物（历史版本）

餐桌观察视图根据实际人物和餐桌的网格边界、主视图宽高比自动拉远镜头，并在画面下方为读数和观察提示预留空间。首次打开、重置、切换餐桌观察视图及快速取景后，都能从更完整的人物与餐桌视角开始观察；窗口尺寸改变时重新适配。

该调整只改变中央外部观察镜头的位置和观察目标，四路 CAM 的镜头配置、HFOV、4:3 投影和当前人体姿势均保持原有逻辑。鼠标滚轮仍可继续拉近或拉远。

## 0.2.3 快速取景锁定当前结构配置（历史版本）

食物取景只搜索人体姿势，按当前活动表体配置进行定位：佩戴距离、表体立起角度、底座连接件旋转均保持用户设置，前摄 / 12 点侧 / 3 点侧及其他侧摄不会自动旋转或翻转表体。唯一例外是活动表体背面的后摄，会自动将表体立起角度设为 **90°**；连接件旋转仍保持当前值。固定底座背摄朝皮肤，仍提示无法取景，不通过翻转表体伪造可用视野。

初始及重置状态的表体立起与连接件旋转均为 **0°**。当前保存的配置与手动参数继续保留；在固定结构下无法完成餐盘取景时明确提示，不放开结构自由度。此前自动生成的 -92° 等旋转值不会在新版快速取景中被重新搜索；如需回到初始结构，可先手动将旋转设为 0° 或重置实验。

## 0.2.2 更靠腕关节的佩戴位置与短参数名（历史版本）

佩戴距腕关节范围扩展为 **10–120 mm**，可以比原来的最小 35 mm 再向手腕靠近 25 mm。距离仍表示表体中心到腕关节的距离，默认 53 mm；表带近腕截面已按腕部收窄的轮廓贴合。靠腕位置会使表壳更接近手背，保留实际网格遮挡，不通过隐藏手部消除遮挡。

三个标签简化为“腕部屈伸”“腕部侧偏”“佩戴距腕关节”，方向解释移到标签与滑块的悬停提示；模块帮助中仍可查看动作说明。

## 0.2.1 可移动佩戴位置与主摄快速取景（历史版本）

- 新增“佩戴距腕关节”：表体中心距腕关节 35–120 mm，默认 53 mm。增大表示向肘部移动；底座、表带及四路镜头共同移动，手部位置不变。底座高度和表带两侧截面随小臂轮廓贴合，避免用固定半径的表带穿入较粗位置。
- 新默认场景为餐桌，主视图打开时聚焦餐盘。从 v1/v2 本机存储升级时，首次也进入餐桌并保留原参数。v3 的手动场景选择仍会保存；JSON 导入保留文件内明确指定的场景。
- 选中 A / B / C / D 就将其作为快速取景主摄，按钮显示“食物取景 · 槽位名”。点击后根据当前镜头实际安装部件、安装面、偏转、倾斜、画面旋转、FOV、佩戴距离和左右腕搜索姿势，再对餐盘中心与四个范围参考点做真实场景遮挡检查。左右腕切换时，已启用的食物取景姿势会重新以同一主摄计算。
- 仅调整身体姿势与允许活动的表体角度，不更改任何镜头安装配置、启用状态、FOV 或佩戴距离，不使用虚拟 lookAt 改写镜头方向。切换其他姿势保留佩戴距离。
- 关闭的镜头、朝皮肤的底座背摄有明确失败提示，保留原姿势；其他无法完整取景的参数组合只提供最接近的姿势，并提示微调，不能视为已获得有效画面。
- 新配置版本为 schemaVersion 3，兼容 v1/v2，缺失佩戴距离时补为 53 mm。

快速取景是几何启发式搜索，不是人体舒适性或结构可实现性的最优解；当前仍使用示意人体、表带和桌面，需实物验证。移动佩戴位置不会模拟表带松紧操作或皮肤压缩。

## 0.2.0 钟点校正、手腕结构与食物取景（历史版本）

- 统一正面观察表盘时的 12 上 / 3 右 / 6 下 / 9 左，修正侧摄镜头、钟点标记与屏幕纹理的左右关系。局部坐标 +Y 是屏幕外法线，+Z 是 12 点，**-X 是 3 点**。
- 手表底座与闭合椭圆表带固定于前臂末端，表体中心距腕关节约 53 mm。中立左腕的 3 点侧朝手部，右腕保留同一实物表盘的方向关系，不镜像表盘和传感器。活动底座旋转仍可自由调整佩戴方向。
- 重建掌骨展开轮廓、拇指与大鱼际、三段手指、指甲和手背肌腱轮廓。左右手拇指位置自动对应。
- 腕部采用两个串联旋转中心及连续变形的表面过渡。屈伸正值为掌屈、负值为背伸；新增侧偏正值朝拇指。手表与表带不会随手掌屈伸旋转。
- 四路画面新增“手部 N%”读数：对图像平面均匀发射 9×7 条射线，统计 35 cm 内首先命中手掌 / 腕部表面的比例；悬停显示人体与表壳遮挡明细。该值是稀疏几何采样，不是精确像素覆盖率。
- 主视图顶部可以切换“视野参照场景 / 餐桌 · 食物取景”；新增“食物取景”姿势及餐桌观察按钮。餐桌包含餐盘、示意主食 / 肉类 / 蔬菜、餐具、杯子。默认食物姿势下可先观察 C 的 12 点侧画面，餐盘范围读数为四个参考角点可见数。
- 配置升级到 schemaVersion 2，兼容旧版导入，新增场景及侧偏状态。改变运动模型后，旧的自定义角度对应的空间视野会发生变化；建议先重置或重新选择姿势，再调节参数。

这是参照人体结构的程序化近似，未使用个体 CT 网格、软组织力学、实际表带压缩或运动捕捉标定。65% / 35% 的双关节分配是便于观察的简化参数，不是从论文推导的通用人体比例。腕关节多中心运动的背景参考：[Rainbow et al., In Vivo Kinematics… (2013)](https://pmc.ncbi.nlm.nih.gov/articles/PMC3557539/)。食物场景用于取景与遮挡验证，尚不实现食物识别、分量重建或卡路里估算。

## 0.1.3 人物外观优化

人物更新为风格化青年男性：连续轮廓的下颌与脸型、贴合头部的侧分短发、细化眉眼与五官、合身深色 Polo、修身长裤和低帮运动鞋。手臂改为渐变粗细的网格，双手具有独立手指。

## 0.1.2 手臂水平内收

新增“手臂水平内收 · 肩部”滑块，范围 -60–90°。正值使抬起的手臂向身体中线移动，负值向外展开；左右腕方向自动对应。这个角度改变肩部的运动平面，与肘部弯曲、前臂绕自身轴线旋转分别控制，不给肘部添加不真实的横向折弯。

“抬腕看表”默认加入 35° 内收，并调整抬臂、弯肘和前臂旋转，使手腕位于身体前方。“抬腕立起 · 双摄”也加入内收并相应调高抬臂角度，以保留前摄的人脸视野。四路摄像头随整条关节链运动。

旧 JSON / 本机保存的配置缺少内收值时按 0° 读取，保留原有姿势。更新后点击“抬腕看表”或“重置实验”，即可应用新的预设。

## 0.1.1 后摄画面方向修复

0.1.0 只指定镜头光轴，未明确传感器画面上方向，导致表体立起后后摄的画面倒置。0.1.1 使用光轴和安装上方向建立完整相机坐标系；前后摄的画面上方向均朝表体 12 点钟侧。这相当于对旧版后摄安装方向作 180° 滚转校正，而非单轴翻转或自拍镜像。

新增每路“画面旋转 · 传感器安装”滑块及 0° / 90° / 180° 快捷键，模拟传感器绕光轴的安装旋转，保持镜头位置和拍摄方向不变。预览、视锥、目标提示和导出 PNG 使用同一相机方向。不会自动把任意佩戴姿势的画面拉平到世界水平线，仍保留真实随动关系。旧 JSON 配置自动补零旋转值。

## 建议的演示顺序

1. 初始“抬腕看表”：观察 A 前摄中的人脸；B 后摄此时通常被底座遮挡。
2. 点击“抬腕立起 · 双摄”：表体绕 6 点钟侧铰链立起 90°。观察 A 前摄看脸、B 后摄看前方标识及物体。
3. 在 0°、45°、90° 之间切换，观察后摄视野逐步露出。表体没有离开腕上的底座。
4. 点击“腕部”放大：查看钟点标记、活动表体、固定底座及彩色镜头位置。
5. 点击 A / B / C / D 画面，分别修改安装位置、安装部件、水平偏转、上下倾斜、水平视场角。
6. 将某一路改为“腕上固定底座”，对比其不会随表体立起而转动的效果。底座背面镜头仍会受到手腕遮挡。
7. 切换“自然下垂”并播放摆臂。暂停会冻结当前姿势，便于观察。
8. 导出 JSON 配置，或保存四路对比 PNG，记录讨论结果。

## 模型约定

- 世界坐标：Y 向上，Z 是人体前方。
- 表体坐标：Y 是屏幕面的外法线，Z 朝 12 点钟方向，-X 朝 3 点钟方向。
- 铰链位于 6 点钟侧，12 点钟侧向上抬起。连接件旋转可改变立起方向；这是通用概念结构，不是品牌实机结构复刻。
- 表背摄像头位于活动表体与屏幕相反的一面。平放时通常被底座挡住；立起后随表体运动，配合抬腕可拍前方。
- “立起”与“完全拆下手持”是不同状态。本版实现腕上立起，不包含完全拆下后的持握模型。
- 前后摄默认光轴相反；它们的实际世界朝向由身体姿势、前臂旋转、活动连接件及表体翻转共同决定；腕部屈伸改变手部遮挡，不带动手表。
- 显示的 FOV 是水平视场角，代码换算为 Three.js 的垂直 FOV。钟点标记以表体为参照，不以观察者视角为参照。
- “人体显示 / 遮挡”关闭时人体也不再参与遮挡，用于诊断镜头方向，不能作为真实佩戴效果。
- 视锥和彩色镜头标记仅在外部观察视图可见；它们不会出现在传感器画面中，也不参与遮挡。

## 适用范围

适合讨论“哪个位置能看到什么、怎样抬腕或立起、会被什么挡住”。不模拟成像清晰度、曝光、低光、镜头畸变、防抖、人脸识别算法或真实人体机械活动约束。人脸提示只是少量点的可见性判断，不是覆盖率测量。手表尺寸、人体比例、铰链范围及镜头参数都是示意值，不能据此作实机定型结论。
